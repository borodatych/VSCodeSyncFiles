## Фраза поддержки в релизах

База фраз — `docs/release-donation-phrases.md` (секции **Активные**, **Отложенные**, **История использования**). Постоянная вступительная строка не меняется: «Если VSCodeSyncFiles оказалось полезным — буду рад благодарности.» Ниже неё подставляется одна юмористическая подпись из «Активных».

Алгоритм перед каждым релизом:
1. **Предложить** варианты из «Активных» — показать пользователю списком.
2. **Сгенерировать новые**, если пользователь не выбрал из активных или попросил ещё.
3. **Спросить про сохранение** после генерации: какие из новых перенести в «Активные», какие в «Отложенные», какие отбросить. Самовольно ничего в файл не записывать — только по явному «сохрани / отложи / выкини».
4. **Записать в «Историю использования»** выбранную фразу с номером версии — чтобы не повторять её на следующем релизе.
5. **Команды пользователя** (применимы и вне релиза):
   - «запомни эту фразу» / «сохрани в активные» → переместить в «Активные».
   - «отложи эту» → перенести в «Отложенные».
   - «выкини / удали эту» → удалить из файла.
6. После любого изменения файла — кратко подтвердить, что и куда переехало.
