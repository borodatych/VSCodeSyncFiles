# Donation Phrases — фразы блока «Поддержать проект» в релизах

База фраз для блока «Поддержать проект» в GitHub Releases.
Workflow выбора и сохранения — в [AGENTS.md → «Фраза поддержки в релизах»](../AGENTS.md).

Перед каждой фразой блока всегда идёт постоянная вступительная строка:

> Если VSCodeSyncFiles оказалось полезным — буду рад благодарности.

Ниже — варианты второй строки (юмористическая подпись).

---

## Активные (готовы к использованию)

1. VSCodeSyncFiles — opt-in донаты, opt-out телеметрия. Всё, как вы любите.
2. Лицензия MIT, подписки нет, бэкдоров не завезли. Если хочется отблагодарить — кнопка ниже.
3. Open source держится на трёх китах: Linux, Git и донатах.
4. Settings Sync хочет аккаунт Microsoft. VSCodeSyncFiles хочет только ваше OneDrive/GDrive/Dropbox/Yandex — и ничего сверху.
5. Файлы синхронизируются сами. Кофе у автора — пока вручную.
6. Cursor берёт $20 в месяц за чат, Copilot — $10 за автокомплит. VSCodeSyncFiles берёт 0₽ за то, что ваши `.bashrc` и `.gitconfig` живут везде одинаково.

## Отложенные (не вошли, можно вернуться)

- Repository.onDidChangeState ушёл в Вальгаллу. Кнопка ниже — за упокой.
- vscode.git API меняется чаще, чем погода в Лондоне. VSCodeSyncFiles догоняет — за ваш счёт нервов и за свой счёт кофе.
- Один TypeError — два упавших extension host'а. Релиз 0.6.2 платит компенсацию.
- Конфигурационная схема `aiMerge` боролась сама с собой четыре строки в Output каждое утро. Теперь не борется. Кофе всё ещё борется.
- Конфликты решаются: keep mine, take theirs или AI-merge. Кофе у автора — keep mine, every time.
- Снапшоты, time-travel scrubber, SARIF-экспорт конфликтов — а в кружке у автора снова пусто.
- P2P-сессии через WebRTC, passkey-разлок через WebAuthn, encrypted bundles. И всё это — за «спасибо». Если есть лишний доллар — будет «спасибо большое».
- DuckDB-WASM аналитика стартует за 400ms, кофеварка автора — за 4 минуты. Несимметрично.
- 148 команд в palette, 50+ настроек, 4 провайдера облака. Поддержка проекта — одна кнопка ниже.
