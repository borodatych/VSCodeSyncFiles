# Документация VSCodeSyncFiles

Карта документов проекта. Каждая строка — живая ссылка: список должен быть
достижим кликом, поэтому ASCII-дерева здесь нет.

Роли документов не пересекаются: **мануалы** отвечают «как сделать»,
**каталог** — «что умеет», **база знаний** — «почему так», **планы** — «что
дальше», **спеки** — «как устроено внутри».

## Руководства — manuals/

- [crossMachinePaths.md](manuals/crossMachinePaths.md) — разная структура папок на разных машинах: привязка файла и папки под другим именем, правка облачной структуры, засев второй машины.

## Что умеет продукт

- [functional.md](functional.md) — каталог возможностей без привязки к версиям: одна запись на возможность.
- [../CHANGELOG.md](../CHANGELOG.md) — что и когда изменилось, по версиям.

## База знаний и контекст

- [knowledge.md](knowledge.md) — инсайты, дорогие при повторном выяснении: неочевидности VS Code API, поведение провайдеров, архитектурные ловушки, договорённости по UX.
- [continuity.md](continuity.md) — подробный контекст проекта для новых участников и агентов.

## Планы

- [roadmap.md](roadmap.md) — хаб планов и указатели на планы по фазам.
- [v1/roadmap.md](v1/roadmap.md) — текущий план работ.
- [v2/roadmap.md](v2/roadmap.md) · [v3/roadmap.md](v3/roadmap.md) — планы соответствующих фаз.
- [v2/deferredWiring.md](v2/deferredWiring.md) — сознательно отложенное.

## Спеки и проработки

- [v2/linkBindings.md](v2/linkBindings.md) — привязки: модель идентичности файла, пер-машинные размещения, папочные правила.
- [v3/canonicalPaths.md](v3/canonicalPaths.md) — правка канонических путей: переезд ключей, сходимость, засев.
- [v2/breakdown.md](v2/breakdown.md) — разбор задач фазы 2.
- [v2/blake3-benchmark.md](v2/blake3-benchmark.md) — замеры хэширования.
- [v2/p2p-smoke-guide.md](v2/p2p-smoke-guide.md) — ручная проверка P2P-передачи.

## Процесс

- [release-donation-phrases.md](release-donation-phrases.md) — фразы блока «Поддержать проект» в релизах и история их использования.

---

Мануалы живут только в `manuals/`, имена файлов — camelCase. Мануалом **не**
являются: каталог `functional.md`, планы `roadmap.md`, база знаний
`knowledge.md`, спеки формата и регламенты — у них свои места выше.
